# Compatibility policy

The public contract of `@processengine/rules` includes:

- `validateRules`, `prepareRules`, `evaluateRules`
- `RulesCompileError`, `RulesRuntimeError`
- formatter helpers
- diagnostics shape
- runtime result shape
- documented public prepared artifact fields
- documented trace contract

Breaking change means changing any of the items above in an incompatible way.
